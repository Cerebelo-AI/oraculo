# Segurança

Este repositório é público. Nada pessoal entra aqui: chaves, tokens, senhas, cookies, serial de
dispositivo, IPs internos, caminhos com nome de usuário ou configurações pessoais.

- Todo push e pull request passa pelo [gitleaks](https://github.com/gitleaks/gitleaks) (ver
  `.github/workflows/gitleaks.yml`), e o GitHub secret scanning com push protection está ligado.
- Achou algo sensível? Abra um aviso privado em *Security → Report a vulnerability*, não uma issue.
